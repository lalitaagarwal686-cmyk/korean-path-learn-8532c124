# Korean Bloom

Build a polished, mobile-first Korean language learning application website, using the attached PDF as the structural/content reference where relevant. Do NOT copy the Arena Infosolution branding or digital-marketing content; reinterpret the document's premium UX principles and page-by-page approach for a Korean-learning product. Create a cohesive responsive web app/website with a premium modern Korean-inspired visual identity, excellent typography, subtle glassmorphism, rounded cards, soft shadows, smooth scroll-reveal/micro-interactions, strong accessibility and SEO-friendly structure. The product should feel like a serious Korean-learning platform for Indian learners, not a generic template.

Core experience: a homepage/landing page for learning Korean, with clear CTAs such as Start Learning, Take Placement Test, and Explore Courses. Include sections for: hero with Korean typography/visuals, trust/social proof, learning-path overview, course levels (Beginner through advanced), Hangul foundations, vocabulary, grammar, speaking/listening practice, TOPIK preparation, AI-powered practice, progress/streak dashboard preview, learning process, testimonials, FAQ, and final CTA. Add dedicated app-like routes/pages for Courses, Learn (lesson interface), Practice, TOPIK, Progress, and Profile/Settings. Include a responsive navigation: desktop header plus mobile bottom navigation where appropriate, mobile menu, sticky learning CTA, and accessible forms/modals.

Learning UI should include lesson cards, Korean word/phrase cards with pronunciation and English/Hindi meanings, audio/play controls, quiz interactions, multiple choice, fill-in-the-blank, flashcards, streak/progress indicators, XP/points, level badges, and a clean lesson completion state. Use realistic sample Korean-learning content, but keep it clearly editable. Avoid copyrighted third-party course content. Build reusable components and a consistent design system. Make the whole experience work beautifully on small Android screens as well as desktop. Do not wait for more instructions: implement the initial full experience now, prioritizing the homepage and core app shell, then the main learning screens.
